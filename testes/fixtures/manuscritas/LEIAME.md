# Fixtures manuscritas

Receitas escritas à mão pela equipe, fotografadas para testar a história H1.4.1.

Todos os dados são **sintéticos**: pacientes, médicos, CRM e medicamentos são fictícios.
Não adicionar receitas reais nem fotos com metadados de localização.

| Arquivo | Uso |
|---|---|
| `receita_legivel.jpg` | letra clara; deve passar sem revisão |
| `receita_dose_ilegivel.png` | dose ilegível; deve ir para revisão |
| `receita_pessima.png` | letra muito ruim; deve ir para revisão |
